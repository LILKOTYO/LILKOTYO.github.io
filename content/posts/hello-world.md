## 前言

这是我使用 Hugo 搭建个人博客后发布的第一篇文章。Hugo 是一个用 Go 语言编写的静态网站生成器，以速度快、配置灵活著称。

## 为什么选择 Hugo

- **速度极快**：Hugo 是目前最快的静态网站生成器之一
- **安装简单**：只需一个二进制文件，无需复杂的依赖
- **Markdown 支持**：使用 Markdown 编写内容，专注于写作本身
- **主题丰富**：社区提供了大量精美主题可供选择

## 快速上手

搭建一个 Hugo 博客只需要几个步骤：

1. 安装 Hugo
2. 创建新站点
3. 选择或创建主题
4. 编写内容
5. 发布

```bash
hugo new site my-blog
cd my-blog
hugo server
```

打开浏览器访问 `http://localhost:1313` 就可以预览你的博客了。

## 总结

Hugo 让搭建个人博客变得非常简单。接下来我会继续分享更多技术笔记和生活感悟。
