## 什么是 Markdown

Markdown 是一种轻量级标记语言，让你可以用纯文本格式编写文档，然后转换为 HTML。它的语法简洁直观，非常适合写博客。

## 常用语法

### 标题

使用 `#` 来创建标题，一个 `#` 是一级标题，两个 `##` 是二级标题，以此类推。

### 强调

- **粗体**：用 `**文字**` 包裹
- *斜体*：用 `*文字*` 包裹
- ~~删除线~~：用 `~~文字~~` 包裹

### 列表

无序列表使用 `-` 或 `*`，有序列表使用数字加 `.`。

### 代码

行内代码使用反引号包裹，如 `code`。代码块使用三个反引号：

```python
def hello():
    print("你好，世界！")
```

### 引用

> 这是一段引用文字。
> Markdown 让写作变得简单而优雅。

### 链接和图片

- 链接：`[文字](URL)`
- 图片：`![描述](图片URL)`

## 小结

掌握了以上基本语法，就足以应对大部分博客写作需求了。Happy writing!
